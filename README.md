# bhe-identity-risk-report-generator
BloodHound Enterprise Identity Risk Report – PDF Edition v1.5

Initial production release of the ReportLab-based PDF reporting engine for BloodHound Enterprise.

Features

* Executive PDF Identity Risk Report
* Executive Dashboard
* Identity Risk Theme reporting
* OpenGraph reporting
* Privilege Zone Intelligence summary reporting
* Technical Evidence Workbook (XLSX)
* Customer branding support
* ReportLab-based renderer

This release represents the frozen production baseline for the PDF Edition.
